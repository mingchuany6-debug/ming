高德 Web + Android 双Key数据探针 1.0

固定 Android Key 绑定信息：
PackageName: com.tungee.amaphybridprobe
SHA1: 8B:08:D1:78:83:1D:AD:D1:2A:05:5D:06:06:15:BE:66:73:34:7B:F6

用法：
1. 在高德控制台新建 Android平台SDK Key，PackageName 与 SHA1 按上面填写。
2. APK 安装到安卓真机。
3. 输入 Android Key、原 Web服务 Key、1~10 个 POI_ID。
4. 勾选协议/隐私确认，点击开始双通道测试。
5. 重点看“疑似额外字段/重点扫描”以及 Android SDK ShowFields.ALL 原始展开结果。

注意：opentime_today / opentime_week 是营业时间，不等于酒店开业日期。
